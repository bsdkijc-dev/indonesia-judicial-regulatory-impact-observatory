# IJRIO v1.0 — PERMA Master Registry (Stage 0)

**Disclaimer:** Independent academic research dataset. Not an official Mahkamah Agung RI database.

## Files
- `perma_registry.csv` / `perma_registry.jsonl`: 29 verified Level-1 PERMA records (2009–2025).
- `perma_legal_status.csv`: Legal status, document type, and amendment/repeal tracking.
- `source_registry.csv`: Level 1 & Level 2 official source provenance.
