# PERMA Regulatory Scorecard Framework — IJRIO v1.0

## 1. Ten Scorecard Dimensions
1. Problem relevance
2. Regulatory coherence
3. Design quality
4. Implementation effectiveness
5. Institutional efficiency
6. Access-to-justice outcomes
7. Stakeholder impact
8. Evidence of outcomes
9. Unintended consequences
10. Regulatory sustainability

## 2. Scale & Missing-Data Rule
- `1` = Very weak
- `2` = Weak
- `3` = Moderate
- `4` = Strong
- `5` = Very strong
- `NOT ASSESSED` = Evidence is insufficient (mandatory when Level 1–3 evidence is absent; missing evidence must never be converted into a low score).

## 3. Aggregation Policy
Dimensions with fundamentally different meanings are **never automatically averaged** into an unweighted composite index. Any future composite index must publish explicit weights and sensitivity checks.

## 4. Recommendation Options (Analytical Only)
- **OPTION A — RETAIN**
- **OPTION B — RETAIN WITH IMPLEMENTATION IMPROVEMENT**
- **OPTION C — AMEND**
- **OPTION D — CONSOLIDATE**
- **OPTION E — REPLACE**
- **OPTION F — REVOKE**
- **OPTION G — FURTHER EVIDENCE REQUIRED**
