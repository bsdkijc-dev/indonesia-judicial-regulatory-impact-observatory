# Kaggle Data Architecture — IJRIO v1.0

*Disclaimer*: IJRIO Kaggle datasets are independent academic research outputs and are **not** official databases of Mahkamah Agung RI.

## Planned Datasets (All Private Pending Human Approval)
1. **PERMA Master Registry Dataset** (`perma_registry.csv`, `perma_registry.jsonl`, `source_registry.csv`)
2. **PERMA Legal Status Dataset** (`perma_legal_status.csv`)
3. **Regulatory Impact Evidence Dataset** (`regulatory_problems.csv`, `regulatory_objectives.csv`, `legal_coherence.csv`, `stakeholder_impacts.csv`, `unintended_consequences.csv`)
4. **PERMA Implementation Indicators Dataset** (`implementation_evidence.csv`, `impact_indicators.csv`, `ria_assessments.csv`, `recommendations.csv`)

## Planned Notebooks
1. `regulatory_trends.ipynb` — Historical PERMA issuance, amendment frequency, and subject-matter distribution.
2. `impact_analysis.ipynb` — Five-PERMA pilot ex-post RIA indicator analysis and causal-design checks.
3. `perma_comparative_analysis.ipynb` — Cross-PERMA scorecard and coherence comparison.

## Mandatory Dataset Package Documentation
Every Kaggle release includes: Description, Data Dictionary, Source Documentation, Methodology, Limitations, Licensing Assessment (`CC-BY-4.0` for metadata/analysis; official legal texts linked rather than redistributed unless permitted), and Update Date.
